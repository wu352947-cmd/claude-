# 拾光手帐

日系 × 中式审美的个人手帐动画网页。直接用浏览器打开 `index.html` 即可。

- **圆窗月景**：跟随鼠标的视差、按当天日期计算的月相、可以点响的风铃
- **今日小记**：心情、待办（完成越多小苗长得越高）、饮水、月历打卡印章
- **二十四节气罗盘**：可拖动旋转，显示七十二候；背景飘落物随季节切换（春樱、夏萤、秋叶桂花、冬雪）
- **拾物板**：可拖动的拍立得、车票、邮票、压花、信封（点击拆信）
- **诗笺**：芭蕉、一茶、杜牧、王维，3D 翻面
- **心愿灯**：写下心愿放飞孔明灯
- 日 / 夜两套配色；所有数据只存在本机浏览器 localStorage

所有插画、纹样与印章均为手绘 SVG / Canvas，无外部图片。字体来自 Google Fonts，加载不到时回退到系统中文字体。

源文件在 `src/journal.html`，修改后运行 `./build.sh` 生成 `index.html`。
