# 拾光手帐

日系 × 中式审美的个人手帐动画网页。直接用浏览器打开 `index.html` 即可。

- **圆窗月景**：WebGL 水墨晕染——开场墨迹从纸上洇开，日夜切换时晨雾与湖景两张照片以墨痕交替；湖面随鼠标泛起涟漪，点击投下水纹，薄雾缓缓流动、按当天日期计算的月相、可以点响的风铃
- **今日小记**：心情、待办（完成越多小苗长得越高）、饮水、月历打卡印章
- **二十四节气罗盘**：卡片顶部的四季照片随罗盘以水墨晕染切换（带缓慢推镜）；可拖动旋转，显示七十二候；背景飘落物随季节切换（春樱、夏萤、秋叶桂花、冬雪）
- **拾物板**：拍立得像相纸一样慢慢显影，拖着摇一摇显影更快；可拖动的拍立得、车票、邮票、压花、信封（点击拆信）
- **诗笺**：芭蕉、一茶、杜牧、王维。翻面时卡片抬起、带回弹地翻转，背面衬与诗意对应的照片，诗句一字一字落墨，最后盖上朱印；每首配一段小景：古池水纹荡开、露珠滑落、霜叶飘落、新雨初停月光渐亮
- **千里江山画卷**：卷轴随滚动展开、平移，可拖动；鼠标悬停是 2.2 倍放大镜，朱点注出柳林、飞瀑、主峰、鉴藏印、长桥
- **心愿灯**：银河星空下的湖面（Canvas 实时倒影）。写下心愿后字会飞进纸灯，灯身鼓起、灯芯点亮，升上夜空后化作一颗星；灯和倒影随水波晃动，鼠标停在灯上显示心愿，点湖面泛起水纹
- 日 / 夜两套配色；所有数据只存在本机浏览器 localStorage

插画、纹样与印章为手绘 SVG / Canvas。WebGL 效果需要通过 http(s) 访问；直接双击打开 `index.html` 时浏览器不允许 WebGL 读取本地图片，会自动退回静态照片。`assets/` 里的照片来自 Pexels（Pexels License，可免费商用），画卷为北宋王希孟《千里江山图》局部（公有领域，Wikimedia Commons）。字体来自 Google Fonts，加载不到时回退到系统中文字体。

源文件在 `src/journal.html`，修改后运行 `./build.sh` 生成 `index.html`。
