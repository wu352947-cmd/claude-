# macOS Tahoe Web

一台运行在浏览器里的 Mac：按 macOS Tahoe（26）的 Liquid Glass 设计复刻，纯 HTML / CSS / JavaScript，无需构建，双击 `index.html` 即可运行（部分联网功能建议用本地服务器打开）。

```bash
cd macos
python3 -m http.server 8080   # 然后访问 http://localhost:8080
```

## 流畅度

像 macOS 的 WindowServer 一样，尽量把动画交给合成器（GPU），主线程只做必要的事：

- **弹簧动画**：窗口打开、缩放、平铺、切换桌面都用阻尼弹簧物理曲线（预先积分后转成 CSS `linear()` 缓动），由合成器线程执行。
- **FLIP 缩放**：绿色按钮缩放、平铺先一次性设好最终尺寸，再用 transform 从旧位置“弹”过去，动画期间不发生重排。
- **拖动窗口**：只改 `transform`，每帧合并为一次写入；几何信息缓存，指针事件里不读布局。
- **程序坞放大**：图标按最大尺寸只栅格化一次，放大只是 GPU 缩放；位置按数学计算，不读 DOM。程序坞按键值增量更新，不再整体重建。
- **按需渲染**：时钟、天气、活动监视器、语音备忘录的动画只在窗口真正可见时运行（被完全遮住、最小化、在其他桌面都会暂停），并限制帧率。表盘缓存为位图，每帧只画指针。
- **去掉昂贵滤镜**：窗口不再逐个使用实时背景模糊；启动台、Safari 起始页使用预先模糊好的墙纸；墙纸异步解码后再交叉淡入；图标与缩略图使用小图。
- **自适应画质**：持续掉帧时自动关闭实时毛玻璃（类似“降低透明度”），保证交互跟手。
- **原生手感**：触控板左右轻扫桌面跟手切换空间；滚动到边缘的橡皮筋回弹；鼠标滚轮也有惯性滑行，撞到边缘会带速度回弹；拖动或缩放窗口时会被其他窗口和屏幕边缘“吸住”（按住 ⌥ 关闭吸附）；把文件拖到程序坞图标上直接用该应用打开；触控板双指捏合可缩放预览和照片里的图片，在桌面上捏合打开启动台、张开退出；快速晃动鼠标指针会临时放大以便找到；菜单选择后淡出；macOS 风格光标与强调色文本选区。

## 快捷键

浏览器会占用一部分 ⌘ 组合键，所以同时提供了 Ctrl / ⌥ 替代：

- 聚焦搜索：Ctrl + 空格 或 ⌥ + 空格
- 启动台：F4 或 ⌥ + L；调度中心：F3 或 Ctrl + ↑；切换桌面：Ctrl + ← / →
- 切换应用：⌥ + Tab；关闭窗口：⌘W 或 ⌥W；退出应用：⌘Q 或 ⌥Q；最小化：⌘M
- 截屏：Ctrl + Shift + 3（整个屏幕）/ 4（当前窗口）；锁定屏幕：⌃⌘Q；Siri：⌥ + S
