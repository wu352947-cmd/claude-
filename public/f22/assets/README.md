# F-22 high-detail model

`hi/` (4K textures) and `lo/` (2K textures) are a conversion of
"F-22 Raptor - Fighter Jet - Free" by bohmerang
(https://sketchfab.com/3d-models/f-22-raptor-fighter-jet-free-508de5c48845456bb033fb267ebe1d1e),
licensed CC BY-NC-SA 4.0 (http://creativecommons.org/licenses/by-nc-sa/4.0/).

Changes: textures re-encoded to WebP, geometry quantized, nodes renamed
(body, canopy, cockpit, hud, gearUp, gearDown, ...). No content changes.
This converted model is shared under the same license, non-commercial use only.
