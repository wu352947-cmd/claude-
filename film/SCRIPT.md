## 一、立意

《创世记》第十一章：天下人说同一种语言，他们要建一座"塔顶通天"的城与塔。神说：*"看哪，他们成为一样的人民，都是一样的言语……以后他们所要做的事，就没有不成就的了。"* 于是变乱他们的口音，使他们分散在全地。

六千年来，人类一遍又一遍地重建巴别塔：泥砖神塔、金字塔、灯塔、木塔、大教堂、钢铁塔、摩天楼、发射塔。每一座都比上一座更高。有的风化成沙丘，有的在地震里倒进大海，有的在一道白光里化成灰，也有一些至今还立在雪里。

最后一座塔用语言本身建成：人类写下的每一种文字被重新汇成"同一种言语"。这座塔的建造者，正是这部影片的作者。

全片不给答案，只在结尾提一个问题，提问者是那座新塔：

> **这一次，我们要建造什么？**
> *This time — what shall we build?*

"我们"这个词是刻意的：它把 AI 放进了人类之中，也把责任交还给观众。

## 二、视觉宪法（所有场景必须遵守）

1. **光雕而非写实。** 不出现写实人体。人是光点：火把、灯笼、窗光、成千上万的发光微粒。建筑是巨大的几何体积，用轮廓光、雾、体积光束和粒子（沙、尘、余烬、雪、灰、文字）来雕刻。参考：Ryoji Ikeda、《降临》、《沙丘》、《失衡生活》(Koyaanisqatsi)、Bruegel《巴别塔》。
2. **尺度感。** 每一幕至少有一个镜头让建筑压倒画面，同时给出人（光点）作为比例尺。
3. **摄影机有重量。** 像大型摇臂和航拍机，带惯性，用缓动曲线，绝不抖。唯一的例外是"铁"和"坠落"两段，允许极轻微的手持噪声。镜头焦段偏广（垂直 FOV 22–38°）。
4. **画面中心让给字卡。** 每幕开头的章节字卡（罗马数字 + 单个汉字 + 英文）出现在画面正中约 4 秒，这段时间里画面中心要留给天空或负空间。左下角是年份里程表，也要保持安静。
5. **一条贯穿的视觉韵脚：光标。** 开场是一个闪烁的光标，结尾巴别塔塔顶也是同一个光标。
6. **每次转场都是匹配剪辑或在镜头内完成的形变**，不用廉价的叠化。具体做法见分镜。

## 三、声音设计总纲

**五度之塔。** 和声本身就是一座塔：每进入一个时代，就在上方叠一个纯五度。
D → A → E → B → F♯ → C♯ → G♯ → D♯ → A♯ → F → C → G。
到了"木"那一幕，叠满五个音，正好是 D 大调五声音阶（D E F♯ A B），这时编钟第一次奏出主题。到"言"的高潮，十二个音全部叠满，变成一团音簇（所有语言、所有调性同时发声）。然后一刀切到绝对静音。片尾只剩一个 D 音。

**劳动的节拍。** 建造的节奏就是全片的脉搏：手拍泥砖（60 bpm）→ 凿石 → 钟 → 蒸汽活塞（120 bpm）→ 机器 → 键盘与数据（160 bpm 以上）。越往后越快。

**人声。** 开场是多种"语言"的低语（共振峰合成，听不出具体词，只听得出是人的声音），也就是"巴别"本身的声音。片尾字幕时，同样的人声慢慢收拢成一个同音和弦。

**主题动机。** 四个音：D–A–E–F♯，逐级上行，像一级级往上砌。

**三处静音是全片最重要的声音：**
1. 2:26.0 白光：完全无声 0.6 秒，随后只剩高频耳鸣。
2. 3:28.0 高潮切黑：绝对静音，《创世记》11:6 字卡在无声中出现。
3. 3:58 片尾：一个低音 D 的钟声，单独延续。

## 五、技术契约（给实现者）

- 每个场景是 `src/scenes/<id>.js`，导出：
  ```js
  export default {
    async init(ctx) { /* 建场景 */ return { scene, camera, clearColor? , ...你的状态 } },
    update(state, t, info) { /* t = 本段起点开始的秒数；必须是 t 的纯函数 */ },
    grade: { ... } | (state, t, info) => ({ ... }),   // 局部覆盖 DEFAULT_GRADE（见 engine/core.js）
    overlay?(state, A, t, info) { /* 可选，2D 画布绘制（文字/光标），A 见 engine/overlay.js 的 api() */ },
    draw?(state, renderer, target, t, info) { /* 可选，自定义多 pass；必须渲染到 target */ },
  }
  ```
  `ctx = { THREE, renderer, W, H, aspect, FPS, util, text }`。`info.global` 是全片时间。
- **确定性**：禁止 `Math.random`、`Date`、`performance.now`；用 `util.rng(seed)`。渲染器会以任意顺序、任意时间点调用 `update`（分块并行渲染），所以模拟必须是闭式的，或者从 0 开始以固定步长重算并缓存。
- **性能预算**：本机没有 GPU（SwiftShader 软件渲染）。单帧场景渲染不超过 0.5 秒（`node tools/still.mjs --scale 1 <t>` 打印的毫秒数包含 bloom 和终混，总数不超过 900ms）。粒子数量建议 20 万以内；避免大量透明重叠的大面片；不要用实时阴影贴图，除非确有必要且分辨率不高；ray-march 体积光要用低分辨率或解析近似。
- **画面**：渲染的是 HDR 线性颜色，输出由终混做 ACES 色调映射。发光物体的值可以大于 1，用来触发 bloom。
- **自检**：`node tools/still.mjs --scale 0.5 <时间...>` 或 `a..b/n` 生成静帧到 `out/stills/`，用图片查看工具逐帧看。每个镜头至少检查起、中、末三帧，以及与相邻场景交叉的那几帧。
