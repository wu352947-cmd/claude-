# 咒术回战 · 领域展开（同人网页游戏）

单文件 3D 开放世界动作游戏（three.js r128，从 cdnjs 加载），第三人称视角，针对手机触屏设计（横竖屏均可），电脑也能用键盘玩。直接用浏览器打开 `jjk/index.html` 即可，无需构建；`jjk/2d.html` 是早先的俯视角 2D 版。

- **3D 表现**：伏魔御厨子的神社从地底升起、天空染成血红、空中斩击切开大楼（上半截沿切口滑落）；无量空处是封闭的星空结界；敌方领域是带熔岩火山或无数手掌的穹顶。

- **开放世界**：6400×6400 的地图，分为咒术高专、涩谷、深山森林、废弃工厂区、旧住宅区五个区域，离中心越远咒灵越强；建筑可以被术式切碎、炸毁。
- **角色**：两面宿傩（解 / 捌 / 开）、五条悟（苍 / 赫 / 茈，常驻无下限）、虎杖悠仁（逕庭拳 / 飞踢 / 黑闪）。
- **领域展开**：开局领域槽已满。
  - 伏魔御厨子：无屏障的开放领域，半径内持续落下「解」「捌」斩击，切碎所有咒灵与建筑，最后以「開」收尾。
  - 无量空处：范围内敌人被无限信息冻结，持续受伤，悟的伤害翻倍。
  - 黑闪乱舞（奥义）：在敌人之间瞬移连续打出黑闪。
  - 领域结束后进入术式烧断。
- **特级咒灵**：漏瑚（盖棺铁围山）、花御、真人（自闭圆顿裹）。被关进敌方领域会受到必中伤害，可用「简易领域」减伤，或展开自己的领域进入**领域对决**（连点按钮压制对方）。
- 操作：左半屏拖动移动，右半屏拖动转视角，右下按键战斗。键盘：WASD 移动 · Q/E 转视角 · J 攻击 · K/L/I 术式 · 空格 闪避 · F 领域 · P 暂停。
