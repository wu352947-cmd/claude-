# 13 · 异地对战（冲刺 8 实现说明）

> 状态：**草案**。程序：`game/src/engine/session.ts`（回合文件、接续检查）、`game/src/client/hotseat.ts`（三种对战方式）；测试：`game/test/pbem.test.ts`。
> 做法依据：[07 §5 冲刺 8](07-Vibe-Coding开发流程.md)——导出 / 导入回合文件，异地对战。

## 1. 玩法

两个人各用自己的设备（手机、电脑都行），不用服务器：

1. 双方打开同一个网页。"记录 / 存档"里把"对战方式"选成**异地对战**，再选"我是德军"或"我是苏军"。
2. 先手方（德军）直接玩。结束阶段，直到轮到对手时，屏幕被遮住，只剩两个按钮。
3. 点**导出回合文件**，把下载的文件通过微信、邮件等发给对手。文件名写明回合和轮到谁，如"kursk-回合文件-第 1 回合-轮到苏军.json"。
4. 对手点**读入对手的文件**，选这个文件，就接着你的进度走。走完他同样导出，发回给你。
5. 重复，直到想定结束。

**第一次读入时：**后手方的网页是自己新开的一局，种子不同。只要这时还没有下过任何指令，读入先手方的文件会直接采用先手方的那一局（种子、位置都以文件为准）。

## 2. 回合文件是什么

就是存档文件（想定 + 种子 + 全部指令 + 状态指纹），多一项"现在轮到谁"。

- 读入时程序把所有指令从头回放，并核对状态指纹。不一致就报错，不会读成一个"看起来对、其实不一样"的局面。
- 同一种子、同一串指令得到同一结果，所以双方不需要同步任何别的东西。骰子由种子决定，对手也没法"重掷"。

## 3. 防止出错

| 情况 | 处理 |
|---|---|
| 读入的文件比你现有进度短（旧文件） | 拒绝，提示"不是接在你现有进度之后的" |
| 读入另一局的文件（种子或指令开头不同） | 同上拒绝 |
| 还没轮到你，点结束阶段、移动、进攻、撤销、重做 | 不能下指令，提示"现在是××行动" |
| 撤销想退回到对手的阶段 | 不允许 |
| 旧版本存的没有"轮到谁"的存档 | 照样能读（向后兼容） |

## 4. 迷雾与它的局限

迷雾按**你自己的一方**显示：敌军单位只有贴近你的单位才看得清，其余显示"?"。

**局限（老实说明）：**回合文件里有对手的全部指令，所以懂行的人从文件里能看出对手所有单位的位置，迷雾在异地对战里是"君子协定"。真正的隐藏需要服务器，不在本冲刺范围。

## 5. 暂不实现

| 事项 | 原因 |
|---|---|
| 服务器、网页联机（实时对战） | 路线图阶段 5–7（04）；现在的纯静态网页没有后端 |

| 自动提醒"轮到你了" | 要有通知服务；现在靠聊天软件 |
