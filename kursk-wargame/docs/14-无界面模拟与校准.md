# 14 · 无界面模拟与校准（冲刺 9 实现说明）

> 状态：**草案**。方法依据 [05 §6](05-史料复原方案.md)。程序：`game/src/sim/`（自动对手、批量运行、统计、报告）；参数：`game/data/sim/bots.json`；测试：`game/test/sim.test.ts`。
> 完整数据报告（1000 局）：[reviews/2026-10-10-S1校准报告.md](reviews/2026-10-10-S1校准报告.md)。

## 1. 怎么运行

```
cd game
npm run sim -- 1000 ../docs/reviews/某某校准报告.md                # 跑 1000 局，写报告
npm run sim -- 200 /tmp/a.md '{"SU":{"goalWhenFirst":"enemy"}}'      # 覆盖自动对手参数做对照
npm run sim -- 200 /tmp/b.md '{"recover":{"own":6,"contested":3,"enemy":1}}'   # 覆盖受损池送修门槛
```

1000 局约 5 分钟。同一种子永远得到同一结果（自动对手没有随机，骰子来自种子），所以报告可以复现。

## 2. 自动对手

**不是历史命令脚本，也不是好 AI。**05 §6.1 要的历史命令脚本需要逐日逐支部队的史料，目前没有；先用最朴素的逻辑，检验"规则与数据组合起来会不会产生离谱结果"：

| | 德军 | 苏军 |
|---|---|---|
| 移动 | 每个单位向最近的、还没占到的目标推进 | 原地防守；有主动权的回合（第 4 回合）机动单位向最近的敌军推进，徒步单位不动 |
| 进攻 | 赔率达到 1.5:1 就打，相邻的所有单位一起上 | 赔率达到 3:1 才打；有主动权的回合 1.5:1 |
| 其他 | 炮兵不进入离敌军小于 2 格的格子；战后总是推进 | 同左 |

## 4. 发现

**已经修掉的（规则问题）**
- 装甲受损原来记在单位出发的格子上，前线格几乎总是"争夺中"。现在记在**战斗发生的战场格**，回合末按这块战场归谁分流，与 02 §4.4 一致。

**没有修、也不该靠调参数硬修的**

| # | 现象 | 原因（已查到的） | 该怎么办 |
|---|---|---|---|
| F1 | 赔率过高（4:1 以上占 65%），攻方几乎不吃亏，德军 74% 夺取普罗霍罗夫卡 | 没有**堆叠 / 正面限制**：相邻的所有单位一起攻一个格子；苏军开局是单格单个单位的稀疏部署；没有**防御纵深、工事、雷场、反坦克支撑点**（02 §5，已在 09、10 列为"后续"） | 先做这些机制，再校准。**不要**去改战斗结果表补偿 |
| F2 | 沙霍沃、维诺格拉多夫卡德军必占（历史上苏军守住或夺回） | 自动对手的苏军**从不夺回**失地，且没有预备队机动 | 自动对手加"夺回目标"，或做历史命令脚本 |
| F3 | 苏军 7 月 12 日装甲损失只有历史的三分之一到一半 | 即使让苏军有主动权时**不看赔率硬冲**，中位数也只有约 92 辆。每次战斗只损失 1–3 步（算子层面的粒度）、每格每阶段只能被攻击一次，一天内装甲损失被"战斗次数"封顶 | 需要看是否应允许对同一格多次进攻、或 CRT 中攻方损失更重；等 F1 的机制补上后再评估 |
| F4 | 德军受损装甲完全损失占 74%，历史上只有约 3%–10% | 即使把"本方控制"门槛调到必回收（6/3/1），德军仍有 66%——因为多数受损发生在敌方控制或争夺的战场。历史上德军战场抢修能力强（回收连、战场控制），本作没有"修理单位 / 抢修能力"这一项 | 02 §4.4 已写"修理速度取决于修理单位与补给"，需要先有补给与修理单位的数据（史料）。**没有史料支持前不加德军回收加成** |
| F5 | 德军党卫军军装甲损失偏高（中位数约 28 辆，历史最多 16 辆） | 与 F1 同源（攻方压倒性优势下仍有 A 结果）；也可能是装甲损失折算偏粗 | 与 F1、F4 一并看 |

**历史上对得上的**：勒扎韦茨（德军）、斯托罗热沃耶（德军）、亚姆基和普罗霍罗夫卡站（苏军守住，在 25%–75% 的区间内）。德军的"能打下来"与"打不下普罗霍罗夫卡站"同时在分布里出现，不是僵死的。

## 5. 敏感性：规则对行为有反应

每组 200 局（主跑 1000 局）。德军目标分 = 中位数，满分 20。

| 变化 | 德军目标分 | 苏军 12 日装甲损失（辆） | 党卫军装甲损失（辆） | 德军占普罗霍罗夫卡 | 受损装甲完全损失占比（德 / 苏） |
|---|---|---|---|---|---|
| 基础（主跑 1000 局） | 18 | 84 | 28 | 74% | 74% / 71% |
| 苏军机动单位每回合都反击 | 15 | 70 | 182 | 72% | 75% / 71% |
| 德军更谨慎（赔率 3:1 才打） | 13 | 42 | 62 | 36% | 76% / 70% |
| 两者同时 | 12 | 52 | 199 | 50% | 77% / 71% |
| 苏军有主动权时不看赔率硬冲 | 18 | 92 | 62 | 64% | 73% / 71% |

| 受损池送修门槛（本方 / 争夺 / 敌方，d6 不大于几点送修） | 苏军 12 日损失 | 完全损失占比（德 / 苏） |
|---|---|---|
| 4 / 2 / 1（现行） | 84 | 72% / 72% |
| 5 / 3 / 1 | 78 | 68% / 65% |
| 6 / 3 / 1 | 76 | 66% / 62% |
| 6 / 4 / 2 | 51 | 52% / 47% |

**解读**：改变任何一方的行为，结果都明显变化，说明规则有反应。但没有哪一组能同时让苏军损失、德军损失和目标归属都对上，说明问题不在某一个参数。

## 6. 这次的决定

| 项 | 决定 | 理由 |
|---|---|---|
| 战斗结果表、列偏移、受损池门槛 | **不改** | 05 §6.3：校准调的是公式参数与 CRT 结构，且要有可靠的历史指标。现在主要偏差（F1–F4）被缺失的机制和自动对手的局限盖住，调参数就是"为了复现结果篡改原因" |
| 装甲受损记录位置 | **改**：记在战场格 | 这是规则错误，不是参数 |
| 胜利点只计装甲完全损失 | **改**：其他兵种损失单列 | 01 §7.2 本来就是这个意思 |
| 历史基准 | **填 16.8** | 历史上德军占着目标 5 分，加上装甲损失折成步数的交换。苏军只含 12 日，偏低（11、13 日数字没查到） |
| 档位分界 | 拟定一组：≥ +10、+4、−4、−10 | 设计参数，待所有者审定 |

**基准的含义**：模拟里德军平均得分 28–29，比历史基准 16.8 高十几分，意思是"现在的规则 + 朴素自动对手，让德军明显比历史更成功"，与 F1 相符。

## 7. 建议的下一步（按对结果影响排序）

1. **堆叠与正面限制**：一个格子最多几个单位参战、一次进攻最多几个单位。这是 F1 的主要原因。
2. **防御纵深、工事、雷场、反坦克支撑点**（02 §5）：苏军防线的核心，没有它苏军的防守太"薄"。
3. **历史命令脚本**：把 12 日 8 时苏军反突击、德军各师的进攻方向写成指令，取代朴素对手（05 §6.1）。
4. **补史料**：第 3 装甲军 11–13 日坦克损失、苏军 11 和 13 日损失、第 7 装甲师等 9 个没放的单位位置。
5. **德军战场抢修**：需要修理单位的史料后再加（F4）。
6. 以上做完后，**重新跑 1000 局校准**，再决定要不要调 CRT。

## 8. 局限

- 自动对手不是历史行为，所以对"某个目标被夺取的概率"这类指标只能当检查，不能当证据。
- 车辆数折算是粗略的：把每个单位战斗序列里的车辆总数除以满编步数。数量级可信，具体数字不可信。
- 历史装甲损失本身口径差一个数量级（击中 / 烧毁 / 完全损失，见 disputes.csv DSP-0028、0029）。判定用的是 Wheatley 的"完全损失"口径。
