# 10 · 战斗（冲刺 5 实现说明）

> 状态：**草案**。规则依据 [02 §4](02-规则系统设计.md)。战斗结果表和所有修正都是 AI 拟定的游戏设计参数（不是史料数字），在 `game/data/rules/combat.json`，⟨待校准⟩。
> 程序：`game/src/engine/combat.ts`（赔率与修正）、`combat-resolve.ts`（结算）；测试：`game/test/combat.test.ts`。

## 1. 流程

1. **谁能打：**
   - 只能在本方战斗阶段或发展阶段进攻；发展阶段与夜间的限制见 [11 §3–4](11-回合流程.md)。
   - 进攻单位必须与目标格相邻。炮兵和反坦克歼击炮兵旅**不能进攻**，只防御（[08 §6](08-单位数值换算公式.md)）。
   - 每个单位、每个目标格每阶段只能参加一次战斗。目标格里的全部敌军一起防御。
2. **赔率** = 攻方攻击合计 ÷ 守方防御合计，向下取到下表的列。数值按剩余步数折算，例如 3 步的单位剩 1 步时只有三分之一。低于 1:2 不能进攻，高于 6:1 按 6:1。
3. **列偏移**（合计最多 ±3）：

| 修正 | 列 | 依据 |
|---|---|---|
| 守方在林地、村庄、镇、沼泽 | −1 | 02 §2 近战地形 |
| 守方在城市 | −2 | 同上 |
| 所有攻方都隔小河 / 铁路路堤进攻 | −1 | 02 §2 |
| 所有攻方都隔大河进攻 | −2 | 同上 |
| 装甲效应：攻方有中/重装甲，守方在开阔地且没有坦克、突击炮、坦克歼击车、反坦克炮单位 | +1 | 02 §4.2（简化） |
| 攻方装甲隔冲沟进攻 | −1 | 02 §2 冲沟是天然反坦克障碍 |
| 诸兵种合成：同一编制的装甲与步兵一起进攻 | +1 | 02 §4.3（简化） |
| 炮兵支援：射程 2 格内的本方炮兵，炮火支援值合计每 3 点 1 列，最多 2 列；攻方右移、守方左移 | ±1–2 | 08 §3.4 |

   - 炮兵每阶段只能支援一次（攻防都算）。本回合移动过的炮兵不能支援（"移动或射击"，参照 Alea、OCS）。
4. **骰子修正：** 素质。攻方最高素质减守方最高素质，每级 ±1，最多 ±2。目前所有单位都是 3 级，所以暂时为 0。
5. **掷 2d6**，加骰子修正（结果限在 2–12 之间），查表。

设计思路：
- 1:1 时双方互有损失。
- 3:1 起守方多半要后撤。
- 6:1 时守方几乎肯定损失并后撤。
- 测试检查了"赔率越高对攻方越有利"在每一行都成立。

## 3. 结果怎么执行

- **损失：**
  - 守方从堆叠最上面的单位开始，每个单位轮流损失 1 步。
  - 攻方按进攻单位的先后轮流损失。
  - 步数降到 0 的单位被消灭。
- **受损池（02 §4.4）：**
  - 坦克、突击炮、坦克歼击车单位损失的步数先记入受损池，界面"对局"面板会显示。
  - 回合末按战场控制分流成"修复"和"完全损失"，见 [11 §5](11-回合流程.md)。
- **撤退：**
  - 全格一起退，程序自动选路线：先选不在敌控制区的格子，再选离攻方最远的，再按格号，保证结果确定。
  - 只能退入敌控制区时，每个单位损失 1 步。无路可退时，每少退 1 格，每个单位损失 1 步。
- **推进（追击）：**
  - 守方格子空出后，进攻过的单位最多 3 个可以立刻占领该格，不计移动力，也不受控制区影响。
  - 推进只能紧接在战斗之后下达，做了别的操作就失去机会。

## 4. 界面

- 在本方战斗阶段点敌军格，信息面板出现"进攻这一格"：
  - 勾选进攻单位。
  - 看攻防合计、赔率、每条列偏移及出处、最终列、各结果的概率。
  - 点"开战（掷骰）"。
- 战后若能推进，同一面板出现"推进"。
- 事件记录写明赔率、骰点、结果、各单位损失与撤退。
- 撤销可以撤回整场战斗。骰子来自对局种子，撤销后重打，结果相同。
