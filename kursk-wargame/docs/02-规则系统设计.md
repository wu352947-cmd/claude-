# 02 · 规则系统设计

> 本文是规则的**架构**，不是最终规则书。所有数值都是待校准的占位，用 `⟨待校准⟩` 标出。
> 原则：先写出"这个机制要表现什么历史现象"，再设计机制，最后用史料检验。

## 1. 回合顺序（每个游戏回合）

```
1. 战略阶段        天气判定 → 战略事件 → 增援/撤出 → 大本营/OKH 指令
2. 空中阶段        双方秘密分配航空兵：制空 / 近距支援 / 遮断 / 侦察
3. 第一方（主动方）
   3.1 指挥阶段    计算各司令部指挥点 → 激活编队、下达任务
   3.2 移动阶段    普通移动、战略移动（铁路/公路）、超越攻击（Overrun）
   3.3 反应阶段    【被动方】预备队反应移动、炮兵拦阻
   3.4 战斗阶段    炮兵准备 → 宣告进攻 → 结算 → 撤退与追击
   3.5 发展阶段    仅限"未战斗或进攻得手"的机动单位再次移动/战斗（闪电战的核心）
4. 第二方         同 3
5. 回合末         补给判定 → 损失分流（可修复/完全损失）→ 修复 → 工事建设 → 战果记录
```

- **主动方**：7 月 5–12 日南北线均为德方先手；苏军反攻阶段改为苏方先手。由想定规定，也可由"主动权"规则决定。
- **夜间回合**：移动力减半、不能发起机动进攻（除非特殊规则）、炮兵与工兵效率提高、修复与补给加倍。

## 2. 地形（以库尔斯克地区实际地貌为准）

| 地形 | 表现 | 机制要点 |
|---|---|---|
| 开阔地/草原 | 库尔斯克高地主体 | 德军远射程火炮优势最大：长身管火炮单位在此防御/进攻得列偏移 |
| 冲沟（балка）| 格边特征 | 对坦克是障碍（移动+⟨待校准⟩），对步兵是隐蔽；苏军防御常以冲沟为反坦克天然障碍 |
| 河流/溪流 | 格边特征，分小/中/大 | 普肖尔河、北顿涅茨河需架桥；佩纳河谷是**沼泽河谷**——小河但对装甲车辆是严重障碍 |
| 村庄/城镇 | 格中心 | 近战地形，抵消远射程优势；"费迪南"等无近防武器车辆在此受罚 |
| 林地 | 格内 | 北线及奥廖尔突出部较多 |
| 高地 | 格内标高 | 观察（炮兵）与防御加成；名高地（如 252.2 高地）作为胜利点 |
| 铁路路堤 | 格边 | 普罗霍罗夫卡附近的铁路路堤对 7 月 12 日的战斗有实际影响 |
| 道路/铁路 | 连线 | 道路分硬面/土路；**雨后土路变泥泞**；铁路用于战略移动与补给 |

## 3. 移动与控制区（ZOC）

- 移动力按**机动类型**（履带/轮式/步行/骑兵）区分，不同地形消耗不同。
- **控制区：**
  - 进入敌控制区必须停止；离开需额外移动力。
  - **德军装甲单位**可进行"超越攻击"（在移动中以足够优势压倒弱小单位并继续前进）。
  - **苏军**防御中的反坦克支撑点（ПТОП）具有**强控制区**：进入其控制区的机动单位不能在本阶段继续移动，即使超越攻击得手。
  - 相邻两个友军单位间的格子形成"控制区连接"（同《Holland '44》思路），表现连续战线。
- **装甲集群渗透**：集中的装甲单位（同一师 3 个以上团级单位协同）在开阔地可降低离开控制区的成本——表现楔形队形（Panzerkeil）的突破力，但在冲沟和雷场前失效。

## 4. 战斗系统

### 4.1 基本框架：赔率战斗结果表 + 列偏移 + 步数损失

选择经典的赔率 CRT（而不是复杂的逐武器模拟），因为：①桌面版可用；②玩家能直观理解；③便于用史料校准（只需调整列偏移与结果分布）。数字版在后台精确计算，只把结果和原因展示给玩家。

```
进攻力合计 : 防御力合计  →  基础列
+ 列偏移：地形、工事、诸兵种合成、装甲效应、炮兵、空中支援、指挥、补给、疲劳
→ 掷骰（2d6 或 1d10，选一种，校准时比较两者分布）
→ 结果：攻方损失步数 / 守方损失步数 / 撤退格数 / 守方是否可"有序后撤"
```

### 4.2 装甲效应（复现 1943 年夏季的装甲对抗）

每个单位有两个额外属性：**装甲等级**（无/轻/中/重）和**反坦克能力**（无/弱/中/强/远程）。

| 情况 | 效果 ⟨待校准⟩ |
|---|---|
| 攻方有装甲、守方反坦克能力弱 | 攻方 +列 |
| 守方有"远程"反坦克（Tiger、"费迪南"、88 炮、部分 76.2/85 mm 反坦克炮）且地形开阔 | 守方 +列 |
| 守方在村庄/林地/冲沟、攻方有装甲 | 远程优势取消，近战修正生效 |
| 苏军坦克**主动接近**（7 月 12 日普罗霍罗夫卡式冲击） | 可抵消远程修正，但攻方损失加重 |
| "费迪南"在近战地形无步兵伴随 | 守方额外 +列（1943 年型无航向机枪，难以对付近身步兵）|

### 4.3 诸兵种合成

- 德军："战斗群"规则——同一师的装甲团 + 装甲掷弹兵团 + 炮兵在同一格或相邻协同进攻，+列。不同师的单位协同时有惩罚（除非军部花指挥点）。
- 苏军：坦克旅 + 摩托化步兵旅（同一坦克军内）协同 +列；步兵师得到独立坦克团支援时 +列。**跨军协同惩罚比德军大**（1943 年苏军协同仍是弱项，见 §6）。

### 4.4 损失：可修复 vs 完全损失（本作的核心机制之一）

库尔斯克"坦克损失"数字的混乱，很大程度来自**可修复损失**与**完全损失**没区分。本作把它做成机制：

1. 战斗中损失的装甲步数先进入"**受损池**"（每个师/军一个）。
2. 回合末，根据**谁控制战场**分流：
   - 战场在己方控制下：大部分可回收，进入修理队列，⟨待校准⟩ 回合后返回；
   - 战场被敌方控制：受损车辆大比例转为**完全损失**。
3. 修理速度取决于修理单位、补给与是否夜间。
4. 胜利点只计**完全损失**。

这会自然复现历史现象：德军在 7 月中旬仍控制南线战场时，大量受损坦克被回收；撤退后，留在原地的受损坦克变成完全损失。苏军同理，第 5 近卫坦克集团军 7 月 12 日的大量损失中有相当部分在后续被修复。

### 4.5 机械可靠性

- 新装备首次投入（"豹"式 D 型）在**前若干回合**每次移动有故障判定，故障车辆进入受损池。
- 长距离公路移动对所有装甲单位有小概率故障——表现装甲兵力随行军自然损耗。

## 5. 防御：苏军纵深梯次防御 & 德军弹性防御

### 5.1 苏军纵深防御（7 月）

- **工事等级**（0–3）按史料在想定开始时预置：第一（主要）防御地带、第二防御地带、集团军后方地带，方面军防御地带。
- **雷场**：格内标记，进攻方受罚并可能在进入时损失步数；工兵可排雷。
- **反坦克支撑点（ПТОП）/反坦克地域**：特殊单位或标记，强控制区 + 对装甲进攻 +列。
- **机动障碍队（ПОЗ）**：可在德军突破方向临时布设雷场的小单位。
- **炮火反准备**：7 月 5 日凌晨的历史事件；苏方可选择时机（时机越准越有效，依赖情报，见 §9）。
- **埋设坦克**：苏方可让坦克单位"掘壕"——防御大增、不能移动（第 1 坦克集团军卡图科夫的做法）。

### 5.2 德军弹性防御（库图佐夫、鲁缅采夫阶段）

- **有序后撤**：受攻击前，德方可宣布受攻单位"迟滞后撤"——放弃格子换取更少损失（需指挥点、且不能被包围）。
- **预设阵地**：哈根防线等后方阵地按史料预置，需要时间与工兵建设。
- **反突击**：德方装甲预备队在反应阶段可向被突破处移动，并在本方回合以"反突击"修正进攻（历史：8 月博戈杜霍夫、阿赫特尔卡附近德军装甲师对苏军坦克集团军的反击）。
- **撤离突出部**："秋游行动"（Herbstreise）式撤退：成功撤出奥廖尔突出部的单位不计损失并获得胜利点，被包围的计重分。

## 6. 指挥与控制（复现两军最本质的不对称）

### 6.1 指挥点（CP）

每个司令部（集团军/军；苏军方面军/集团军/坦克集团军/坦克军）每回合产生指挥点，用于：激活编队移动/进攻、发展阶段行动、跨编队协同、有序后撤、反应移动、建立工事、转移补给优先级。

### 6.2 德军：任务式指挥（Auftragstaktik）

- 德军军部 CP 较多；**发展阶段**主要为德军装甲单位服务。
- 师级可在没有军部 CP 的情况下执行"上一回合任务的延续"（任务惯性：降低指挥成本）。
- 限制：**最高统帅部干预事件**——某些决策（撤退、跨集团军群调动）需要通过事件或高额 CP；希特勒的命令可能冻结某些单位。

### 6.3 苏军：计划驱动、逐步成熟

- 苏军集团军在**回合开始前**提交"作战计划"（目标格 + 投入单位）；计划内行动 CP 成本低，偏离计划的行动成本高。
- **大本营代表**（朱可夫、华西列夫斯基）作为可放置的"代表"标记：所在方面军 CP +⟨待校准⟩，可批准释放预备队。
- **学习曲线**：苏军跨军协同惩罚、反应移动能力随战役进程按日程表改善（7 月初 → 8 月）。这是"不对称平衡"的关键旋钮之一，也最需要史料支撑（参考 Glantz《Colossus Reborn》关于 1943 年苏军作战能力演变的论述）。

### 6.4 苏军大纵深进攻（8 月）

- **突破—发展**两段式：步兵集团军 + 炮兵突破军打开缺口；**快速集群**（坦克集团军 = 方面军快速集群；坦克军 = 集团军快速集群）在缺口打开后**投入**。
- 投入快速集群需要：缺口宽度 ≥ ⟨待校准⟩ 格、方面军 CP、该集群处于集结状态。
- 一旦投入，快速集群在若干回合内获得"纵深行动"加成（忽略部分控制区、补给延伸），但离开补给范围后迅速衰减——表现 8 月苏军坦克集团军在哈尔科夫以西被德军反突击打痛的历史。

## 7. 补给

- **补给源**：铁路终点站 → 集团军补给站 → 单位（追溯路径，以移动力或格数计）。
- **弹药/燃料**分开：德军装甲师有"燃料等级"，发展阶段与长距离移动消耗燃料；苏军炮兵有"弹药储备"，炮火准备消耗大量弹药。
- **铁路修复与破坏**：退却方可破坏铁路；**8 月 3 日起的"铁路战"**（游击队大规模破袭）作为事件削弱北线德军补给。
- 断补给：战斗力下降、不能修复、多回合后步数损失。

## 8. 空中力量

- 双方每回合有若干**航空点**（德：第 6 航空队/第 1 航空师在北，第 4 航空队/第 8 航空军在南；苏：第 16 空军集团军在北，第 2、第 17 空军集团军在南，草原方面军的第 5 空军集团军为预备）。
- 先结算**制空**，再按制空结果分配**近距支援（列偏移）/遮断（移动成本、补给）/侦察（揭示隐藏单位）**。
- 专用反坦克机（Hs 129、Ju 87G "卡农鸟"；苏方伊尔-2 携 ПТАБ 反坦克子母弹）作为特殊攻击选项，只对装甲目标有效。
- 历史上德方初期局部制空、随后逐日衰减——由出击率随回合下降、苏方航空点增长来表现，不用硬编码。

## 9. 情报与战争迷雾

- **数字版**：默认隐藏敌方单位类型/实力，接触、侦察、空中侦察后逐步揭示。
- **桌面版**：算子正面朝下（或使用"堆叠顶层标记"），接触时翻开。
- **苏方战前情报优势**：苏方开局知道德军主要突击方向的大致范围（历史上苏军通过多渠道获得了较准确的进攻情报），可据此调整炮火反准备时机——但情报以"范围 + 可信度"给出，而不是全知。
- **苏方欺骗（маскировка）**：假单位、假阵地；草原方面军的存在与位置对德方隐藏。

## 10. 天气

- 按日：晴 / 多云 / 雷雨 / 持续降雨。
- 想定可选"历史天气"（使用逐日记录，见史料方案）或"随机天气"（按 7–8 月该地区气候概率表）。
- 影响：空中出击率、土路移动成本（泥泞持续若干回合）、河流涨水（架桥难度）。

## 11. 事件系统

事件分三类，均数据驱动（见技术架构中的事件 DSL）：

| 类型 | 例子 | 处理方式 |
|---|---|---|
| **固定历史事件** | 7 月 10 日西西里登陆；7 月 12 日库图佐夫行动开始 | 必然发生，日期固定 |
| **条件事件** | 德方是否中止堡垒（受战线、损失、西西里形势影响）；第 2 SS 装甲军是否被调往米乌斯河/意大利 | 触发概率取决于局势，给玩家可选应对 |
| **玩家决策事件** | 苏方是否向大本营请求提前释放草原方面军；德方是否发动"罗兰" | 选择有代价（CP、胜利点、后续时间表）|

## 12. 苏德不对称机制总表

| 维度 | 德军 | 苏军 |
|---|---|---|
| 指挥 | 任务式指挥、CP 多、发展阶段、任务惯性 | 计划驱动、偏离计划成本高、大本营代表、随时间改善 |
| 编组 | 战斗群：同师诸兵种合成加成 | 坦克军/坦克集团军作为快速集群投入 |
| 装甲 | 少而精；Tiger/"豹"/"费迪南"远程优势；新装备故障 | 多而轻；T-34 机动性好但远程吃亏；英美援助坦克；需要接近作战 |
| 防御 | 弹性防御、有序后撤、反突击、预设后方阵地 | 纵深梯次防御、工事、雷场、反坦克支撑点、埋设坦克 |
| 炮兵 | 质量好、数量少；依赖空中支援补足火力 | 数量巨大、炮兵突破军、火箭炮；炮火反准备 |
| 空中 | 初期局部优势、专用反坦克机 | 数量逐步占优、伊尔-2 + 反坦克子母弹 |
| 后勤 | 燃料与弹药紧张；修理回收能力强 | 铁路补给为主；游击队铁路战支援 |
| 信息 | 对苏军预备队情况掌握不足 | 战前情报优势；欺骗与伪装 |
| 战略约束 | 西西里、米乌斯河、希特勒干预 | 大本营控制预备队；反攻时间表 |

## 13. 复杂度预算

把每条规则标上复杂度成本（1–3），总预算控制在 S1 教学想定 ≤ 15 点，全规则 ≤ 45 点。超预算时，优先砍掉"不影响玩家决策"的规则，或把它放进数字版后台自动处理（例如机械故障、修理时间）。
